# Neo Noise: Project Summary

> **Status**: Validated Prototype (v2.0)
> **Goal**: Replace random noise with "Semantic Interference" for procedural generation.

## 1. Executive Summary
**Neo Noise** is a deterministic procedural generation system. Unlike Perlin/Simplex noise, which relies on interpolated random gradients, Neo Noise simulates the **Semantic Interaction** of latent glyphs derived from an input "Inscription" (e.g., "FIRE", "QUEST").

This ensures that the "physics" of the generated field are derived from the *meaning* of the seed word, not just its random value.

---

## 2. Core Technology

### The Algorithm
1.  **Holographic Seeding**: The Inscription is hashed into a single 32-bit integer.
2.  **Latent Field**: Every $(x,y)$ coordinate contains a "Ghost Glyph" (Type + Magnitude) derived deterministically from the seed.
3.  **Pairwise Interference**: Pixel intensity is calculated by interacting neighbors (e.g., `Cross` + `Diagonal` = High Energy).
4.  **Resolution-Aware Normalization**: The output is normalized against theoretical bounds, not local min/max, ensuring consistent scaling for Level-of-Detail (LOD).

### The Temporal Operator
To prevent static/dead terrain, we implemented an **Anti-Entropy** evolution step:
*   $\Delta Field = (Diffusion \times \nabla^2 F) - Decay + Feed$
*   This simulates "Geologic Time" (smoothing) and "Life" (vitality retention), preventing the system from collapsing to grey noise.

## 3. The 4-Layer Architecture
We defined a standard protocol for deriving Game World data from the Neo Field.

| Layer | Derivation | Game Logic Role |
| :--- | :--- | :--- |
| **STRUCTURE** | Raw Neo Field | **Heightmap**. Defines continents, mountains, and oceans. |
| **FLOW** | Field Gradient ($\nabla F$) | **Movement**. Defines rivers, wind tunnels, and trade routes. |
| **CONSTRAINT** | Laplacian ($\nabla^2 F$) | **Obstacles**. Defines cliffs, walls, and impassable terrain. |
| **VITALITY** | Anti-Entropy Simulation | **Biomass**. Defines spawn points, forests, and civilization. |

## 4. Validation & Testing

### A. Automated Test Suites
We implemented 5 Python test suites (`testing/`):
1.  **Invariance**: Confirmed Resolution Stability ($\Delta < 0.01$) and Spatial Isotropy.
2.  **Composition**: Confirmed that `FIRE` $\ne$ `FIER` (Order matters).
3.  **Semantic**: Validated linear interpolation between concepts (Mixing).
4.  **Temporal**: Verified that the Anti-Entropy term prevents heat death.
5.  **Game Reliability**: Confirmed perturbations (Locality Shock) do not explode globally.

### B. World Simulation
**`neo_world_sim.py`** spawned autonomous agents in a generated world.
*   **Result**: Agents successfully identified high-vitality zones (Cities) and migrated along high-flow paths (Trade Routes).
*   *Proof*: See `samples/simulation/sim_QUEST.png`.

### C. 3D Manifestation
**`neo_mesh_exporter.py`** generated 3D meshes for Blender.
*   **Refinement**: We realized raw noise is "Bedrock" (Jagged). Applying the Evolution (Erosion) step created widely superior, rolling terrain.
*   **Texture**: We synthesized "Biome Maps" by compositing the 4 layers (Green Vitality, Blue Flow) directly onto the mesh.

## 6. Known Limitations / Next Steps
*   **Hydraulic Erosion**: The "Flow" layer calculates steepness, not water accumulation. True rivers require a hydraulic routing pass (particle erosion).
*   **Biome Variety**: Currently defined by simple thresholds. Future work involves clustering the "Semantic Axes" to define complex biomes.
