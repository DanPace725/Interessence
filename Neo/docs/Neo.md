# Neo System Overview

## Core Concept
Neo is the unified computational substrate of Interessence. It is not just a collection of symbols, but a **functional geometric system** that encodes information, computation, constraint, and agency into the physical world.

It functions simultaneously as:
1.  **Language**: A script for encoding meaning.
2.  **Architecture**: A structural blueprint for object generation.
3.  **Circuitry**: A geometric logic system for spells and crafting.
4.  **Genetics**: The hereditary code for entity variation.

## Integration with RPE
Neo acts as the primary interface for the **Relational Primitive Engine (RPE)**. When actors interact with the world, they are often reading, writing, or navigating Neo structures.

-   **Glyphs as Parameters**: Each glyph in the system biases the six Relational Primitives (Ontology, Geometry, Dynamics, etc.).
-   **Inscriptions as Programs**: Sequences of glyphs form complex instruction sets (RP-Lang) that the engine evaluates.
-   **Geometry as State**: The physical orientation and visibility of glyphs contribute to the "Signal" field that drives state changes.

## The NeOgham Substrate
The system is built on **NeOgham**, a 5x5 grid extension of the historical Ogham alphabet.

-   **Dimensionality**: It is inherently 3D, designed to be carved on edges. Information is split across faces, requiring movement (embodiment) to fully access.
-   **Completeness**: Use 25 glyphs to form a complete basis set for geometric and logical operations.

## Key Systems

### Dimensional Spellcasting
Magic is the act of "reading" active geometry.
-   **Observer-Relative**: Effects depend on the caster's position relative to the inscription.
-   **Cooperative**: Complex spells require multiple perspectives (players) simultaneously.

### Geometric Crafting
Crafting is circuit assembly.
-   **Component-Based**: Items contain partial glyph fragments.
-   **Emergence**: Correctly joining components completes glyphs, activating latent properties.

### Object Generation
The world is constructed from its own description.
-   **Name = Form**: The NeOgham inscription of an object's name parametrically generates its 3D mesh.
-   **Mutation**: "Typos" or linguistic drift in a name literally warp the physical form of the object.
