## Notes on Structure
-   **Orientation**: Determines which geometric face or vector the glyph occupies.
-   **Marks**: Correlates to "Magnitude" or signal intensity.
-   **Structural Bias**: A hint at the Relational Primitive effect. See **[Glyph_Signal_Compendium.md](../Neo%20Signals/Glyph_Signal_Compendium.md)** for the detailed signal definitions.
