# The Relational Clearing

A small browser-based Interessence experiment about memory, partial knowledge, constraint, and consequence.

## What this tests

- Five individually designed creatures choose among forage, rest, seek, flee, and explore tendencies.
- Each creature acts from local signals and its own condition rather than complete world state.
- Attend, nourish, and ward interventions change persistent observer memories.
- Creature-to-creature bonds form and erode through co-presence and competition.
- A finite focus budget prevents the player from attending to everything.
- Resource, distress, and bond overlays expose the otherwise hidden simulation for inspection.
- Seeded randomness makes unattended runs reproducible.

## Run locally

```powershell
npm run dev
```

Open the local URL printed by the development server.

## Validate

```powershell
npm test
```

The build and rendered-shell tests verify the deployable app, deterministic kernel markers, and illustrated creature renderers.
